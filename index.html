操作说明

1. 对照需求看套餐

估算每月流量和同时在线的手机、电脑数量。只看价格容易选小，只看最高档又可能浪费。以对比区功能列表为准。

2. 完成订阅并保存链接

下单成功后你会得到一条订阅地址。请自行备份，不要发到公开群组。之后换设备时仍用同一条链接导入。

3. 下载并安装客户端

打开本页客户端下载区域，按自己的系统选择应用。安装来源以该区域提供的入口为准，避免去来路不明的第三方搬运页。

4. 导入订阅并连接

在客户端中找到订阅或 URI 导入，粘贴链接后更新列表，选一条线路连接。菜单名称因软件而异，流程都是「导入 → 更新 → 连接」。

5. 按场景切换线路

网页浏览、会议和娱乐对线路的要求不同。遇到卡顿时先更新订阅再换节点；流量将尽时回到套餐区考虑升级，而不是反复重装客户端。

常见问题

快柠檬是什么？和普通 VPN 有何关系？

快柠檬提供机场订阅与 VPN 梯子式的网络加速入口。你购买的是可在客户端里更新的订阅，而不是某一款捆绑安装包。连接之后用于跨境访问和日常加速，具体能解锁哪些应用，以所选套餐说明为准。

第一次使用应该从哪一步开始？

建议顺序是：读简介与场景 → 打开套餐对比 → 订阅 → 到客户端下载安装 → 按操作说明导入链接。不要先到处找节点名称，订阅更新后列表会在客户端内显示。

如何选择套餐，会不会选错？

先数清同时要在线的设备，再估计视频、下载是否频繁。轻度浏览可靠较低档，多设备或娱乐、游戏需求再看高阶卡片里的功能。套餐权益以对比模块文字为准，正文不会另行改写价格或额度。

客户端下载后怎样导入订阅？

打开应用，进入订阅、配置或 URI 相关菜单，粘贴订阅地址并更新。成功后刷新节点，点选一条线路连接。若导入失败，检查链接是否完整、客户端是否为下载区提供的版本。

可以多台设备一起用吗？

可以，但同时在线数量受套餐限制。超出额度时，后接入的设备可能连不上。更换手机或电脑前，先在旧设备断开，或以对比区标注的台数为准规划。

流量用完或连接不稳定怎么办？

当月流量耗尽后加速通道通常会受限，可等待周期重置或升级套餐。不稳定时先更新订阅、更换线路，并确认不是本地网络本身中断。不要把所有问题都归因于某一条未在本页列出的节点名称。
